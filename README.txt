Бот записи гостей «Гостеприимство Аврама» — исходники
=====================================================

ЧТО ВНУТРИ
  manage.py            — точка входа Django
  start.sh             — запуск продакшена: gunicorn (админка) + python3 bot.py (бот)
  bot.py               — сам бот: long polling, кнопки, диалог гостя
  core/                — приложение Django
    models.py          — Settings (настройки бота), Family (семьи и их лимит мест), Booking (заявки)
    schedule.py        — расчёт ближайших трапез и остатка мест у семьи
    admin.py           — админка для хозяев
    migrations/        — миграции базы (0001…0008)
    templates/         — шаблон главной страницы
  gostibot/            — конфиг проекта (settings.py, urls.py, wsgi.py)
  selftest.py          — оффлайн-проверка бота на КОПИИ базы (Telegram подменяется заглушкой)
  selftest_settings.py — общие настройки для selftest
  db.sqlite3           — копия рабочей базы на момент выгрузки (семьи, настройки, заявки)

ЧЕГО ЗДЕСЬ НЕТ (специально)
  .env                 — там токен бота и код хозяина. Рядом лежит .env.example:
                         скопируйте его в .env и впишите свои BOT_TOKEN и OWNER_CODE.
  admin_password.txt   — логин/пароль админки. Создайте нового суперпользователя:
                         python3 manage.py createsuperuser

КАК ЗАПУСТИТЬ У СЕБЯ
  1) python3 -m venv venv && . venv/bin/activate
  2) pip install django gunicorn requests
  3) cp .env.example .env  и впишите BOT_TOKEN, OWNER_CODE
  4) python3 manage.py migrate
  5) python3 manage.py createsuperuser          — доступ в админку
  6) PORT=8000 bash start.sh                    — админка на /admin/, бот в long polling

ЛОГИКА ЗАПИСИ
  /start -> «Записаться в гости» -> выбор трапезы (пятница вечер / суббота день)
  -> выбор семьи (видно, сколько мест осталось) -> имя -> телефон -> число гостей
  -> подтверждение -> заявка «ждёт» + уведомление хозяевам с кнопками Подтвердить/Отклонить.

ОГРАНИЧЕНИЯ
  - Заявок на одну трапезу — без ограничения.
  - У каждой семьи свой лимит гостей на трапезу (поле «Мест за трапезу», сейчас у всех 10).
    Считаются люди: сумма guests по активным заявкам этой семьи на эту дату и трапезу.
  - Максимум гостей в одной заявке — настройка «Максимум гостей в заявке».

ПРОВЕРКА БЕЗ TELEGRAM
  python3 selftest.py   — прогоняет весь сценарий на копии /tmp/selftest.sqlite3,
                          рабочую базу не трогает.
